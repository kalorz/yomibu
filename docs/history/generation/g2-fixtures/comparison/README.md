# Public synthetic G2 comparison

All three inputs are original synthetic permission data dedicated to the public
domain under CC0-1.0, reusing the public G2 pet-rest example and authored slot
combinations. They contain no learner records, credentials, source corpus or A1
held-out material. Tuple labels and grammar declarations are user assertions,
not independently verified language evidence.

`manifest.json` fixes two code commits, revisions, inputs, six exact request bodies
(without trailing newlines), independently checked byte counts/SHA-256 hashes and
12 alternating scheduled attempts. Only developer prompt text differs between
versions; selected tuples, complete grammar, response schema and provider settings
are identical. Full local inputs include permitted but unselected words.

Status: **not run**. Snapshots record what the binaries send, not model obedience.
