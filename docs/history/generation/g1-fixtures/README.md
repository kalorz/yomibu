# G1 synthetic fixtures

Archived engineering evidence for the retired implementation; see
[generation history](../GENERATION_HISTORY.md).

The `dog-cat.json` and `topic-verbs.json` permissions were written for G1 on
2026-10-04 and are dedicated to the public domain under CC0-1.0. They contain no
learner data or copied exercises. The latter adds a topic marker and polite past/
negative-past forms with run/sleep vocabulary. Permissions do not require every
word or form to appear, and generated candidates are not accepted exercises.

Local HTTP responses in the tests are original synthetic envelopes, not captures
from a live provider or evidence of Japanese exercise quality.
